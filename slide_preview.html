Tech Stack

  • • Frontend: HTML5, Vanilla JS (ES6+), CSS3 (Modern Dark/Light UI)
  • • Backend: Java 21, Spring Boot 3.4.3 REST API (Maven)
  • • Database: In-Memory Concurrent Store (PostgreSQL / JPA Architecture)
  • • AI Engine: Heuristic STAR Evaluator + LLM Integration (OpenAI/Gemini)
  • • Authentication: Session & Token Security, CORS Registry
  • • Deployment: Vercel (Frontend) + Render (Docker JVM) + GitHub

Key Technical Highlights

  • • Real-time AI Mock Interviews: Adaptive category & difficulty questioning
  • • Automated STAR Method Evaluation: Quantitative scoring (0–100) & actionable feedback
  • • Duolingo-Style Gamification: Daily streaks (🔥), XP counters (⚡), & badges
  • • Interactive Game Arena: Live coding challenges & category quests
  • • Dual-Mode Audio: Browser-native Speech-to-Text & Synthesizer
  • • Production Zero-Config Deploy: Containerized Spring Boot on Render & Vercel CDN
